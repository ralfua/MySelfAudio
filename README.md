# АудіоСелфі

**АудіоСелфі** — Android-застосунок для голосових нотаток, персональних аудіонагадувань і будильників. Створюй нагадування власним голосом, слухай їх у потрібний час і формуй щоденні звички у своєму ритмі.

> **Короткий опис для GitHub:** АудіоСелфі — Android-застосунок для запису голосових капсул, аудіонагадувань і персональних голосових будильників.

## Можливості

- Запис аудіо з попереднім прослуховуванням і збереженням у бібліотеці.
- Створення нагадувань на обрану дату й час із повторенням одноразово, щодня, щотижня або у вибрані дні.
- Голосові будильники з циклічним відтворенням і поступовим збільшенням гучності.
- Відкладання нагадувань і будильників.
- Бібліотека аудіо з пошуком, категоріями, обраним, перейменуванням, імпортом і керуванням відтворенням.
- Вбудовані звукові пейзажі та українські голосові фрази, які створюються синтезатором мовлення на пристрої.
- Віджет для швидкого запису та перегляду найближчого нагадування.
- Статистика щоденної активності, світла й темна теми.

Записи й імпортовані аудіофайли зберігаються у сховищі застосунку на пристрої.

## Вимоги

- Android 7.0 (API 24) або новіший.

## Дозволи Android

Застосунку потрібен дозвіл на мікрофон для запису аудіо. Для нагадувань і будильників використовуються сповіщення та системний розклад будильників; доступність точного часу спрацювання залежить від версії Android і налаштувань пристрою.

## Технології

Kotlin, Android SDK, Room, AndroidX, Material Components, Navigation, WorkManager і Kotlin Coroutines.
